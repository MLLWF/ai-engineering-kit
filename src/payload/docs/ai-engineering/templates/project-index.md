# Project Index

> 事实类型：index
> 事实源：否

## 入口规则

- 本文件是项目事实库根入口。AI 从本文件下钻到分区文件。
- 本文件只维护事实路由和当前入口指针，不承载事实正文。
- 项目需要新事实类型时，先在本文件登记路由和维护边界。

## 事实路由

| 需要的信息 | 事实源 | 定位 |
|---|---|---|
| 项目背景（目标、范围、约束、现状） | `background.md` | 项目目标、范围、约束、现状和上下文 |
| 重要决策及取舍 | `decisions.md` | 重大方向选择、放弃选项、原因、影响和依据 |
| 项目架构（边界、模块、数据流） | `architecture.md` | 系统边界、模块关系、数据流、外部系统/硬件边界和关键依赖关系 |
| 计划与执行（阶段、任务、测试、验收） | `planning/` | 阶段、任务、状态、测试标准、测试入口、运行结果、执行日志和验收结论；初始为单文件，首个任务写入时升级目录 |
| 依赖资源（缺口、外部依赖、权限） | `resources.md` | 硬件、工具链、文档、权限、外部依赖、获取路径、可用状态和阻塞影响 |
| 未决问题（待拍板、假设、阻塞） | `questions.md` | 待拍板、假设、归属暂不清或暂无法继续处理的问题；定期遍历迁移，不是永久分区 |
